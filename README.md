# Renewable Energy Output Prediction Using Decision Tree Regression

## Project Overview
This project uses **Decision Tree Regression in R** to predict solar energy output based on environmental and weather-related parameters.

## Objectives
- Predict solar energy production using environmental data.
- Identify important factors influencing energy output.
- Evaluate prediction performance using regression metrics.

## Technologies Used
- R Programming
- Decision Tree Regression
- RStudio
- CSV Dataset

## Methodology
1. Dataset collection and preprocessing.
2. Handling missing values.
3. Feature selection.
4. Splitting the dataset into 80% training and 20% testing data.
5. Training the Decision Tree Regression model.
6. Evaluating performance using MAE, RMSE, and R².

## Dataset Features
- Solar radiation
- Sunshine duration
- Air temperature
- Wind speed
- Air pressure
- Relative humidity

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Project Structure
- `model.R` – R source code.
- `Solar Power Plant Data.csv` – Dataset.
- `Renewable Rnergy Prediction.Rproj` – RStudio project file.
